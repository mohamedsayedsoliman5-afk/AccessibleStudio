# AccessibleStudio Pro v3.1
**استوديو الموسيقى والتوزيع الميسر للمكفوفين وضعاف البصر والمبصرين**
*Accessible Mini-DAW & Music Production Studio with Screen-Reader-First Architecture, Dual Physical & SoundFont Synth Engine, Individual Note Editor, Arpeggiator, and Full Interactive GUI.*

---

## 🌟 نظرة عامة (Overview)

**AccessibleStudio Pro v3.1** هو محطة عمل صوتية رقمية مصغرة (Full Accessible DAW) متطورة تم بناؤها وتطويرها خصيصاً لتمكين الموسيقيين والموزعين المكفوفين من إنتاج وتوزيع الموسيقى باحترافية تامة، مع واجهة استوديو رسومية عصرية وتفاعلية للمبصرين والزملاء في الاستوديو.

تتضمن هذه النسخة حزم مكتبات الصوت وقارئات الشاشة بالكامل (FluidSynth DLLs, NVDA Client DLLs, SoundFont default.sf2)، بالإضافة إلى محرك التوليف الفيزيائي المدمج، ومحرر النوتات الفردية، ونظام الأربيجيتور، ومصفوفة المقاطع (Pattern Banks)، والمقامات العربية بربع التون.

---

## 🎹 الإضافات والمميزات الجديدة في إصدار v3.1

1. **محرر النوتات الفردية الناطق (F3 Individual Note Editor):**
   - تمكين الكفيف من التنقل بين النوتات المسجلة في أي تراك نوتة بنوتة.
   - سماع اسم النوتة، أوكتافها، موضعها الزمني بدقة، ومدتها بالملي ثانية مع معاينة صوتية فورية.
   - إمكانية تعديل طبقة أي نوتة مسجلة صعوداً أو هبوطاً (نصف تون أو أوكتاف كامل).
   - إزاحة توقيت النوتة للأمام أو للخلف (Nudge Timing).
   - حذف أي نوتة خاطئة مسجلة دون الحاجة لإعادة تسجيل التراك بالكامل!

2. **الأربيجيتور وتقاسيم المقامات (Ctrl + A Arpeggiator & Maqam Run):**
   - 5 أنماط تشغيل للأربيجيتور: (متوقف، صاعد UP، هابط DOWN، صاعد هابط UP-DOWN، وتقاسيم شرقية MAQAM RUN).
   - نمط التقاسيم الشرقية يقوم بعزف درجات المقام العربي المختار تلقائياً بتوافق نغمي إبداعي.

3. **قفل السلم الموسيقي على المقام (Backslash `\` Scale Lock):**
   - عند تفعيله، يتم قفل جميع مفاتيح الكيبورد على درجات المقام المختار فقط (مثل البياتي أو الرست)، مما يمنع عزف أي نغمة نشاز أو خارجة عن السلم.

4. **الرش الشرقي التريملو (Slash `/` Oriental Tremolo):**
   - محاكاة دقيقة وعالية السرعة لتقنية الرش السريع على أوتار العود والقانون والوتريات.

5. **مصفوفة المقاطع وتسلسل الأغنية (Pattern Banks & Song Chain):**
   - 4 مقاطع موسيقية مستقلة لكل مشروع (`Ctrl + 1`, `Ctrl + 2`, `Ctrl + 3`, `Ctrl + 4`).
   - إمكانية نسخ ولصق المقاطع (`Ctrl + C`, `Ctrl + P`).
   - وضع تسلسل الأغنية الكاملة (`Ctrl + G Song Chain Mode`): يقوم بتشغيل مقاطع الأغنية (المقدمة، الكوبليه، المذهب، والصولو) تلقائياً بالتتابع لإنتاج أغنية متكاملة.

6. **إدارة الأصوات وقارئات الشاشة (`Ctrl + V`):**
   - استكشاف أصوات النظام الحديثة (Windows OneCore Voices) وأصوات SAPI، وتفضيل الأصوات العربية (هدى، نايف، سلمى، شاكر، طارق، ليلى، ماجد).
   - التبديل الفوري بين الأصوات أو التحويل بين قارئ الشاشة النشط (NVDA / JAWS) وصوت النظام.
   - حفظ التفضيلات تلقائياً في ملف `user_settings.json`.

7. **تضمين ملفات DLL وملف SoundFont كامل (default.sf2):**
   - الحزمة التنفيذية للويندوز تأتي مزودة تلقائياً بمكتبات FluidSynth الرسمية و SoundFont عام عالي الجودة لضمان أقصى نقاء صوتي، مع استمرار عمل المحرك الفيزيائي المدمج كخط دفاع دائم.

## ⌨️ دليل اختصارات لوحة المفاتيح الكامل (Complete Cheatsheet)

| الاختصار | الوظيفة |
| :--- | :--- |
| **F1** | تفعيل أو إيقاف دليل المفاتيح التفاعلي الناطق (Key Tutor) |
| **F2** أو **Ctrl + R** | بدء التسجيل (مع عد تنازلي 4 نبضات) أو إيقاف التسجيل وحفظه |
| **F3** | **فتح أو إغلاق محرر النوتات الفردية الناطق لتعديل أو حذف أي نوتة مسجلة** |
| **F4** أو **Ctrl + L** | تفعيل أو إيقاف التكرار التلقائي (Loop) |
| **F5** | فتح أو إغلاق منظم إيقاع الطبول ذو الـ 16 خطوة |
| **F6** أو **Ctrl + Q** | تنفيذ الضبط الإيقاعي الذكي (Quantize) للنوتات |
| **Ctrl + F6** | تغيير شبكة الضبط الإيقاعي (1/8, 1/8T, 1/16, 1/32) |
| **F7** أو **-** | خفض سرعة الإيقاع BPM بمقدار 5 نبضات |
| **F8** أو **+** | زيادة سرعة الإيقاع BPM بمقدار 5 نبضات |
| **F9** | تحميل قالب إيقاعي جاهز في تراك الطبول (مقسوم، بلدي، صعيدي، ملفوف، مهرجانات، تراب، إلخ) |
| **F10** أو **Ctrl + D** | تفعيل أو إلغاء وضع العزل (Solo) للتراك الحالي |
| **F11** أو **Ctrl + M** | كتم أو إلغاء كتم التراك الحالي (Mute) |
| **F12** | التبديل بين ناطق اللغة العربية والإنجليزية |
| **Space** | تشغيل أو إيقاف جميع التراكات / تبديل قوة الضربة في منظم الطبول |
| **Tab** | قراءة تقرير ناطق شامل عن حالة المشروع والتراك والمقام |
| **Up / Down** | التنقل بين التراكات الثمانية (وفي محرر النوتات لتعديل طبقة النوتة) |
| **Left / Right** | اختيار الآلة الموسيقية (وفي محرر النوتات للتنقل بين النوتات) |
| **Ctrl + Left / Right** | التنقل السريع بين عائلات الآلات الموسيقية الـ 16 |
| **Alt + Up / Down** | رفع أو خفض مستوى صوت التراك الحالي |
| **Alt + Left / Right** | توجيه صوت التراك الحالي (يسار / منتصف / يمين) |
| **Alt + PageUp / PageDown** | زيادة أو تقليل مستوى صدى الصوت (Reverb) |
| **Alt + Home / End** | زيادة أو خفض مستوى مؤثر الصدى التكراري (Delay) |
| **PageUp / PageDown** | رفع أو خفض طبقة العزف أوكتاف لأعلى أو لأسفل |
| **Ctrl + PageUp / PageDown** | تغيير طول اللوب (1، 2، 4، 8، 16، 32 بار) |
| **Shift + Left / Right** | تعديل درجة النغم ترانسبوز بمقدار نصف تون |
| **Home / End** | زيادة أو خفض قوة لمس المفاتيح (Velocity) بمقدار 10 |
| **Insert** | تفعيل أو إيقاف دواسة الرنين المتصل (Sustain Pedal) |
| **Slash `/`** | **تفعيل أو إيقاف الرش الشرقي التريملو للعود والقانون** |
| **Backslash `\`** | **تفعيل أو إيقاف قفل السلم الموسيقي على المقام المختار** |
| **Ctrl + A** | **التبديل بين أنماط الأربيجيتور وتقاسيم المقامات** |
| **Ctrl + B** | التبديل إلى المقام العربي التالي (رست، بياتي، صبا، سيكاه، حجاز، نهاوند، كرد، عجم) |
| **Ctrl + N** | تغيير درجة ركوز المقام العربي |
| **Ctrl + K** | التبديل بين أنماط العزف والكوردات (نغمة مفردة، أوكتاف، ميجور، ماينور، خامسة) |
| **Ctrl + 1 .. 4** | **اختيار المقاطع الموسيقية من 1 إلى 4 (Pattern Banks)** |
| **Ctrl + C / Ctrl + P** | **نسخ ولصق المقطع الموسيقي الحالي** |
| **Ctrl + G** | **تفعيل أو إيقاف وضع تسلسل الأغنية الكاملة (Song Chain Mode)** |
| **Ctrl + V** | **التبديل بين الأصوات الناطقة المتاحة (Voice Selection)** |
| **Ctrl + Shift + V** | **التبديل بين أولوية قارئ الشاشة وصوت النظام** |
| **Ctrl + Shift + Up/Down** | **تسريع أو إبطاء سرعة نطق الصوت** |
| **Ctrl + Z / Ctrl + Y** | التراجع عن التعديل (Undo) / إعادة الخطوة (Redo) |
| **Ctrl + S / Ctrl + O** | حفظ جلسة العمل (`session.json`) / استرجاع جلسة العمل |
| **Ctrl + E** | تصدير المشروع فوراً إلى ملف ميدي وملف ماستر ويف |
| **Delete / Backspace** | مسح نوتات التراك الحالي (وفي محرر النوتات لحذف النوتة المحددة فقط) |
| **Escape** | الخروج من محرر النوتات، أو منظم الطبول، أو دليل المفاتيح، أو إغلاق التطبيق |

## 🚀 التثبيت والتشغيل السريع (Quickstart)

### 1. عبر النسخة التنفيذية المستقلة للويندوز (Recommended for End Users)
لا تحتاج لتثبيت بايثون أو أي مكتبات:
1. حمّل ملف `AccessibleStudio-Windows-x64.zip` من صفحة [Releases](../../releases).
2. فك الضغط في أي مجلد على جهازك.
3. اضغط مرتين على `AccessibleStudio.exe` ليعمل البرنامج فوراً، وسيقوم بالنطق فوراً عبر قارئ الشاشة ومحاكاته الصوتية.

### 2. التشغيل من السورس كود (For Developers)
```bash
git clone https://github.com/mohamedsayedsoliman5-afk/AccessibleStudio.git
cd AccessibleStudio
pip install -r requirements.txt
python main.py
```
