# AccessibleStudio Pro
**استوديو الموسيقى والتوزيع الميسر للمكفوفين وضعاف البصر والمبصرين**
*Accessible Mini-DAW & Music Production Studio with Screen-Reader-First Architecture, Dual Physical Synth Engine, and Full Interactive GUI.*

---

## 🌟 نظرة عامة (Overview)

**AccessibleStudio Pro** هو محطة عمل صوتية رقمية مصغرة (Mini-DAW) متطورة تم بناؤها من الصفر لتوفير تجربة إنتاج وعزف موسيقي استثنائية وسلسة للمكفوفين، مع واجهة استوديو رسومية عصرية وتفاعلية للمبصرين والمعلمين والزملاء في الاستوديو.

يتميز البرنامج بدمج كامل لقارئات الشاشة (NVDA / JAWS / Windows SAPI) مع إشارات صوتية نغمية (Earcons)، ومحرك توليف صوتي فيزيائي مدمج لا يتطلب أي مكتبات خارجية مفقودة، مع دعم كامل للعزف الشرقي بربع التون والمقامات العربية.

---

## 🎹 المميزات الرئيسية (Core Features)

1. **دعم مباشر وفوري لقارئ الشاشة (NVDA & SAPI):**
   - اتصال فوري عبر `nvdaControllerClient.dll` و `cytolk` لنطق التغييرات في الزمن الحقيقي دون تأخير.
   - تشغيل النطق في خيط منفصل (Background Worker) لمنع أي تجميد أثناء العزف المباشر.
   - دليل المفاتيح التفاعلي الناطق (**F1 Key Tutor**): استكشاف أي مفتاح ووظيفته الموسيقية قبل عزفه.

2. **نظام الإشارات الصوتية النغمية (Earcons):**
   - مؤشرات سمعية واضحة لأوامر: بدء التسجيل، إيقاف التسجيل، التراجع (Undo)، الإعادة (Redo)، تصحيح الإيقاع (Quantize)، ونقرات الميترونوم.

3. **محرك التوليف الصوتي المزدوج (Dual Synthesis Engine):**
   - **FluidSynth SoundFont:** يدعم ملفات `.sf2` بدقة عالية مع معالجة Pitch Bend لربع التون.
   - **محرك صوتي فيزيائي مدمج (Zero-Dependency Physical Synthesizer):** توليف بالمعادلات الرياضية وNumPy يحاكي الآلات الطبيعية حتى في حال عدم توفر FluidSynth:
     - خوارزمية **Karplus-Strong** للأوتار الفيزيائية (العود الشرقي، القانون، الجيتار الكلاسيكي والمعدني).
     - توليف تركيبي هارموني لبيانو الجراند أكوستيك.
     - توليف الأورغن، الباص، الوتريات (Strings)، والنحاسيات (Brass).
     - محاكاة فيزيائية لأنفاس الهواء لآلة **الناي والفلوت**.
     - محاكاة حقيقية لضربات الطبلة الشرقية: **دم، تك، كا، ورِق بصاجات**، بالإضافة لطقم الدرامز الغربي (Kick, Snare, Hi-Hats, Clap).

4. **المقامات العربية والربع تون (Arabic Maqamat & Microtones):**
   - ضبط دقيق لدرجات المقامات: **رست، بياتي، صبا، سيكاه، حجاز، وعجم**.
   - إمكانية تغيير درجة الركوز (Root Note) والتنقل الفوري بين المقامات بضغطة زر.

5. **سيكوانسر احترافي متعدد التراكات (8-Track Sequencer):**
   - 8 تراكات متزامنة (التراكات 1-7 للآلات النغمية، والتراك 8 مخصص لإيقاعات الطبول).
   - مكسر متكامل: تحكم بمستوى الصوت (Volume 0-127)، التوجيه البانورامي (Pan L/C/R)، ومستوى الصدى (Reverb 0-127)، وأزرار كتم الصوت (Mute) والعزل (Solo).
   - التكرار التلقائي (Loop) بأطوال مختلفة (1, 2, 4, 8, 16, 32 بار).
   - ميترونوم ناطق مع عد تنازلي 4 نبضات (Count-in) قبل بدء التسجيل.
   - ضبط إيقاعي ذكي (Smart Quantization) بدقات: 1/8, 1/8T, 1/16, 1/32.
   - نظام تراجع وإعادة متقدم (Undo/Redo) يحفظ حتى 32 خطوة سابقة.

6. **منظم إيقاع الطبول ذو الـ 16 خطوة (16-Step Drum Machine):**
   - شبكة إيقاعية 16 خطوة سهلة التصفح بأسهم الاتجاهات مع نطق قوة الضربة (قوية أكسنت، متوسطة، خفيفة، ملغاة).
   - قوالب إيقاعية عربية وغربية جاهزة: **مقسوم مصري، بلدي، صعيدي، ملفوف، أيوب، وحدة طربية، هاوس، هيب هوب، وروك**.

7. **تصدير كامل للعمل (Master Export Pipeline):**
   - تصدير كامل إلى ملفات **Standard MIDI (.mid)** متعددة التراكات مع تضمين أحداث ضبط الربع تون.
   - تصدير صوتي نقي ماستر **Stereo WAV (.wav)** بدقة 44100Hz و 16-bit مع معالج منع التشويه (Soft Tanh Limiter).
   - حفظ واسترجاع جلسة العمل بالكامل في ملف `session.json`.

8. **واجهة رسومية بصرية كاملة (Visual Studio GUI):**
   - تصميم مظلم وأنيق للاستوديوهات بدقة 1200x740 بكسل.
   - عدادات ذروة صوتية حقيقية Master Stereo VU Meters.
   - خط زمني تفاعلي (Piano Roll) يعرض النوتات ومؤشر التشغيل المتحرك (Playhead).
   - بيانو تفاعلي مرئي بـ 32 مفتاح يوضح بالضوء المفاتيح المعزوفة في نفس اللحظة.

## ⌨️ دليل اختصارات لوحة المفاتيح (Shortcuts Cheatsheet)

| الاختصار | الوظيفة |
| :--- | :--- |
| **F1** | تفعيل أو إيقاف دليل المفاتيح التفاعلي الناطق (Key Tutor) |
| **F2** أو **Ctrl + R** | بدء التسجيل (مع عد تنازلي 4 نبضات) أو إيقاف التسجيل وحفظه |
| **F3** أو **Ctrl + T** | تفعيل أو إيقاف صوت بندول الإيقاع الميترونوم |
| **F4** أو **Ctrl + L** | تفعيل أو إيقاف التكرار التلقائي (Loop) |
| **F5** | فتح أو إغلاق منظم إيقاع الطبول ذو الـ 16 خطوة |
| **F6** أو **Ctrl + Q** | تنفيذ الضبط الإيقاعي الذكي (Quantize) للنوتات |
| **Ctrl + F6** | تغيير شبكة الضبط الإيقاعي (1/8, 1/8T, 1/16, 1/32) |
| **F7** أو **-** | خفض سرعة الإيقاع BPM بمقدار 5 نبضات |
| **F8** أو **+** | زيادة سرعة الإيقاع BPM بمقدار 5 نبضات |
| **F9** | تحميل قالب إيقاعي جاهز في تراك الطبول (مقسوم، بلدي، صعيدي، إلخ) |
| **F10** أو **Ctrl + D** | تفعيل أو إلغاء وضع العزل (Solo) للتراك الحالي |
| **F11** أو **Ctrl + M** | كتم أو إلغاء كتم التراك الحالي (Mute) |
| **F12** | التبديل بين ناطق اللغة العربية والإنجليزية |
| **Space** | تشغيل أو إيقاف جميع التراكات / تبديل قوة الضربة في منظم الطبول |
| **Tab** | قراءة تقرير ناطق شامل عن حالة المشروع والتراك والمقام |
| **Up / Down** | التنقل بين التراكات الثمانية |
| **Left / Right** | اختيار الآلة الموسيقية السابقة أو التالية |
| **Ctrl + Left / Right** | التنقل السريع بين عائلات الآلات الموسيقية الـ 16 |
| **Alt + Up / Down** | رفع أو خفض مستوى صوت التراك الحالي |
| **Alt + Left / Right** | توجيه صوت التراك الحالي (يسار / منتصف / يمين) |
| **Alt + PageUp / PageDown** | زيادة أو تقليل مستوى صدى الصوت (Reverb) |
| **PageUp / PageDown** | رفع أو خفض طبقة العزف أوكتاف لأعلى أو لأسفل |
| **Ctrl + PageUp / PageDown** | تغيير طول اللوب (1، 2، 4، 8، 16، 32 بار) |
| **Shift + Left / Right** | تعديل درجة النغم ترانسبوز بمقدار نصف تون |
| **Home / End** | زيادة أو خفض قوة لمس المفاتيح (Velocity) بمقدار 10 |
| **Insert** | تفعيل أو إيقاف دواسة الرنين المتصل (Sustain Pedal) |
| **Ctrl + B** | التبديل إلى المقام العربي التالي (رست، بياتي، صبا، سيكاه، حجاز، عجم) |
| **Ctrl + N** | تغيير درجة ركوز المقام العربي |
| **Ctrl + K** | التبديل بين أنماط العزف والكوردات (نغمة مفردة، أوكتاف، ميجور، ماينور، خامسة) |
| **Ctrl + Z** | التراجع عن آخر تعديل (Undo) |
| **Ctrl + Y** | إعادة الخطوة السابقة (Redo) |
| **Ctrl + S** | حفظ جلسة العمل في ملف `session.json` |
| **Ctrl + O** | استرجاع جلسة العمل المحفوظة |
| **Ctrl + E** | تصدير المشروع فوراً إلى ملف ميدي وملف ماستر ويف |
| **Delete / Backspace** | مسح جميع النوتات المسجلة في التراك الحالي |
| **Escape** | الخروج من منظم الطبول، أو دليل المفاتيح، أو إغلاق التطبيق |

## 🚀 التثبيت والتشغيل السريع (Quickstart)

### 1. عبر النسخة التنفيذية المستقلة للويندوز (Recommended for End Users)
لا تحتاج لتثبيت بايثون أو أي مكتبات:
1. حمّل ملف `AccessibleStudio-Windows-x64.zip` من صفحة [Releases](../../releases).
2. فك الضغط في أي مجلد على جهازك.
3. اضغط مرتين على `AccessibleStudio.exe` ليعمل البرنامج فوراً، وسيقوم بالنطق فوراً عبر قارئ الشاشة NVDA ومحاكاته الصوتية.

### 2. التشغيل من السورس كود (For Developers)
```bash
git clone https://github.com/mohamedsayedsoliman5-afk/AccessibleStudio.git
cd AccessibleStudio
pip install -r requirements.txt
python main.py
```
